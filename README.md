# Netflix Data Analysis with Python

### Project Overview
This project explores Netflix data using Python to practice data cleaning, data preprocessing, exploratory data analysis (EDA), 
and data visualization. The analysis aims to understand patterns in the dataset and explore factors such as Average voting, 
popularities, and Popular genre, Release dates available in the dataset.

This project was completed as part of my learning journey by following a tutorial from a YouTube channel called Theiscale where I 
learned many things. Also I used Matplotlib for the visualizations instead of Seaborn( the one used in the video), while practicing 
rest of the techniques.

### Objectives
* Load and inspect the Netflix movies dataset.
* Clean and preprocess the data for analysis.
* Explore important variables and patterns in the data set.
* Analyze Popularities, Voting and other stuff.
* Create visualizations to communicate observations from the data.
  
### Project Workflow
* Loaded and inspected the dataset.
* Examined data types, missing values, irrelevant information and data quality.
* Cleaned and preprocessed the data.
* Conducted exploratory data analysis.
* Created visualizations using Matplotlib.
* Reviewed the results to understand patterns in the dataset.

### My Analysis:
Drama is the most popular and frequent genre in the data set with the rating more than 18.5%
among the other 19 genres given in the data set. The Most popular movie having genre of Action, 
Adventure and sci-fic is Spider-Man: No Way Home while United stated vs billie holiday and Threads movies got the lowest 
rating. Last but not the least, most of the movies got released in the year 2020.
